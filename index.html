Introducción

Este proyecto forma parte de la iniciativa de garantizar la calidad y confiabilidad del software mediante pruebas exhaustivas. Nuestro grupo se enfoca específicamente en el desarrollo y ejecución de estrategias de testing avanzadas para validar el comportamiento, rendimiento y robustez de la aplicación Baby Buddy.

🎯 Objetivo principal: Implementar un conjunto completo de pruebas automatizadas utilizando herramientas modernas de testing.

🍼 Baby Buddy

¿Qué es?

Baby Buddy es una aplicación web para el seguimiento del cuidado de bebés.

Características

  • Registro de alimentación
  • Monitoreo de sueño
  • Gestión de pañales
  • Seguimiento del crecimiento

✨ ¿Por qué Baby Buddy?

Complejidad funcional

Permite aplicar testing avanzado.

Stack tecnológico

Python + Django ideal para pruebas.

Impacto real

Sistema crítico de cuidado infantil.

Puntos de prueba

API, UI y lógica de negocio.
