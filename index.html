Introducción

Este proyecto forma parte de la iniciativa de garantizar la calidad y confiabilidad del software mediante pruebas exhaustivas.

Objetivo principal: Implementar pruebas automatizadas para asegurar la calidad del software.

🍼 Baby Buddy

Aplicación web para gestionar actividades de bebés como alimentación, sueño y crecimiento.

Características

  • Registro de alimentación
  • Monitoreo de sueño
  • Gestión de pañales
  • Seguimiento de crecimiento

Tecnología

Pytest

Framework de testing en Python
