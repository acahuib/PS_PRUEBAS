🧸 Baby Buddy

Proyecto de Pruebas de Software - Hito 1

📌 Descripción del Producto

Baby Buddy es una aplicación web open source diseñada para ayudar a padres y cuidadores a registrar y monitorear actividades del bebé como alimentación, sueño, cambios de pañal y actividades diarias.

El sistema permite organizar información importante para mejorar la toma de decisiones en el cuidado infantil.

🎯 Objetivo del Proyecto

Evaluar y analizar el sistema Baby Buddy desde el enfoque de pruebas de software, validando su funcionamiento, calidad y comportamiento en escenarios reales.

⚙️ Funcionalidades principales

  • Registro de alimentación (lactancia y biberón)
  • Control de horas de sueño
  • Registro de cambios de pañal
  • Seguimiento de actividad (tummy time)
  • Historial completo del bebé

🛠️ Tecnologías utilizadas

Python Django Docker HTML CSS PostgreSQL / SQLite

🧪 Enfoque de Pruebas de Software

Este proyecto se analiza mediante técnicas de pruebas para garantizar su funcionamiento correcto.

  • ✔ Pruebas funcionales (registro de actividades)
  • ✔ Pruebas unitarias (validación de funciones)
  • ✔ Pruebas de interfaz (formularios y entradas)

Se identifican puntos críticos del sistema como registro de datos, almacenamiento y visualización de información.

✨ ¿Por qué Baby Buddy?

  • Sistema real con uso práctico en el mundo
  • Permite aplicar múltiples tipos de pruebas
  • Basado en Django (ideal para testing)
  • Gestiona datos críticos del usuario
